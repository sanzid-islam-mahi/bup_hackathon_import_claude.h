Problem

Turn English into an optimal schedule.

Given a 24-hour campus scenario plus 1–3 operator notes, return the cheapest schedule that obeys every note.

Input EXAMPLE

// operator note
"Reduce solar to 20% from 1 PM to 3 PM."

// becomes
{
  "hours": [13, 14],
  "factor": 0.2
}

What "obeys" means

  • 24 hourly entries — grid, solar, battery
  • Six directive types — solar, reserve, no-charge, no-discharge, grid cap, no-op
  • Constraints — energy balance, battery continuity, end-of-day neutrality
  • Objective — minimize total cost = Σ grid × tariff

Interpretation

Notes → structured directives.

Natural language hides structure. Hidden cases paraphrase — we win with a tight prompt, a deterministic pre-parser, and safe-fail validation.

The hard part

"Drop solar to 20%" and "leave roughly one-fifth" are the same directive.

How we win

  • Tight prompt — 10+ window phrasings, factor = fraction remaining
  • Time-phrase parser — [13, 14] from "1 PM to 3 PM"
  • Pydantic per type — specialized models, not generic dicts
  • Safe-fail — bad note becomes no_op, never a crash

Output JSON

// in
"Cap grid at 200 from 6 PM until 9 PM."

// out
{
  "note_index": 0,
  "directive_type": "max_grid_window",
  "structured_adjustment": {
    "hours": [18, 19, 20],
    "max_grid_kwh": 200
  }
}
